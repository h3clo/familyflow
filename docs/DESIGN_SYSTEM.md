# Family Flow — Design System (원칙 vs 미확정)

운영: [PROJECT_GUIDE.md](PROJECT_GUIDE.md) · 결정: [DECISIONS.md](DECISIONS.md) §6 · 구조: [ARCHITECTURE.md](ARCHITECTURE.md)

**이 문서는 디자인 토큰을 확정하지 않는다.**  
승인된 UX 원칙과, 아직 고르지 않은 시각·IA를 분리해 둔다. 승인 전 전면 UI 재구현·토큰 고정을 하지 않는다.

## 1. 승인된 UX 원칙 (제품 합의)

근거: [PRODUCT_DIRECTION.md](PRODUCT_DIRECTION.md) A형, [DECISIONS.md](DECISIONS.md) §5–6.

1. **가구 중심.** 개인 생산성 앱이 아니라 우리 집 운영을 돕는다.
2. **홈 = 오늘 챙길 일.** 장보기·재고·식단은 도구이며 최종 UX의 전부가 아니다.
3. **입력은 짧게.** 이미 있는 정보로 제안하고, 반복 관리 부담을 줄인다.
4. **AI는 보조.** 긴 채팅이 주인공이 아니다. 필요할 때 쓰는 진입점이 맞다.
5. **중요 변경은 승인 후.** ActionProposal 미리보기 → 사용자 승인 → 적용.
6. **기술 내부 구조를 일반 사용자에게 드러내지 않는다.** (키·RLS·엔진 이름 남발 금지)
7. **첫 클라우드 방문은 로그인/가입이 우선.** 더보기 탐색을 강요하지 않는다.

사용자가 앱을 열면 바로 알 수 있어야 하는 것:

- 지금 우리 집에 어떤 일이 있는가?
- 오늘 먼저 처리할 일은 무엇인가?
- 장보기·재고·식단은 어디서 관리하는가?
- AI 도움은 언제·어떻게 받는가?

## 2. 현재 구현된 IA (구현됨 · 디자인 확정 아님)

코드 탭바 (`src/app.js`):

| 탭 | 역할 요약 |
| --- | --- |
| 홈 | 오늘 저녁 추천, 규칙 제안, 말해 보세요 |
| 식생활 | 장보기 · 재고 · 식단 세그먼트 + 다음 할 일 코치 |
| 가족 | 집 안 프로필(이름·역할 메모) |
| 더보기 | 설정·클라우드·로컬 AI 등 |

이 구조는 **동작하는 현황**이다. 내비 4탭은 DECISIONS §6에서 채택. 비주얼 토큰은 미확정.

## 3. 시각 조정 메모 (미동결)

구현 중 점진 조정 중. 시안 비교용으로만 남긴다.

- 홈 비주얼 하이브리드: A 풀블리드 패턴 사진 + B 네이비 `이대로`/텍스트 `바꾸기`/쿨 그레이
- 저녁 사진: `야채찜`/`야채구이` × 고정 소스 카탈로그를 **프리베이크 JPG**로 두고 매칭만 함 (런타임 텍스처·AI 이미지 생성 없음). 홈 반복 질림 완화 + 단일 이미지 로드.
- 홈 저녁 카드에 「추천 근거」번호 리스트는 두지 않음 (내부 랭킹 신호는 유지)
- 식생활 세그먼트는 세그먼트 컨트롤로 한 줄 유지
- AI는 홈 전체를 차지하는 채팅보다 **필요할 때 쓰는 패널**

## 4. UX 상호작용 — 승인됨 (비주얼과 분리)

2026-11-10 경로 **B**: UX 상호작용은 확정, **비주얼 토큰은 구현하며 다듬기**.  
상세: [DECISIONS.md](DECISIONS.md) §6.1.

- 홈 핵심: 오늘 저녁 추천 → 이대로 / 바꾸기 → 승인 후 저장
- 확인된 재고·식단만 근거. 추측 금지. 빈 상태 명시
- 식생활 영역에서 장보기·재고·식단 접근 (IA는 방향 채택, 비주얼 미확정)

과거 Calm Ops / Focus / Pulse 및 Quiet Clarity / Clear Action / Home Steady 시안은 **비교 참고**일 뿐 최종 팔레트가 아니다. 와이어 D도 기준 아님.

## 5. 시각 디자인 — 미확정 (구현 중 조정 가능)

다음을 **최종 확정하지 않는다.** 구현 PR에서 점진 조정하되, 토큰 “동결”은 별도 승인.

- 색상 팔레트
- 타이포그래피
- 컴포넌트 형태·카드·그림자·라운드 규칙
- 라이트/다크 기본값

현재 쿨 그레이·네이비·Manrope/Noto Sans KR·패턴 사진 오버레이 등은 **구현 중 스타일**이며 승인된 최종 디자인 시스템이 아니다.

## 6. 문서·작업 규칙

- UX 원칙 변경 → `DECISIONS.md` + 본 파일 원칙 절만
- 시각 토큰·IA 확정 → **사용자 승인 후에만** DECISIONS에 올리고 구현
- 시안 검토 전 전면 UI 재작성 금지 (`AGENTS.md`)
